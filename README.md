# IG Leads — أداتك الشخصية لاستخراج بيانات إنستغرام العامة

## المصادر المتاحة
- **Following:** الحسابات التي يتابعها حساب معيّن.
- **Followers:** متابعو حساب معيّن.
- **المتفاعلون مع ريل أو منشور:** المعلّقون، أو المعجبون، أو الاثنان معاً.
  الصق رابط الريل (من زر المشاركة ← نسخ الرابط). صاحب الريل يُستبعد تلقائياً،
  ومن علّق وأعجب معاً يظهر أولاً، ونص أول تعليق لكل شخص يظهر في عمود Comment.

لكل حساب تستخرج الأداة: الاسم، البايو، الإيميل (من قسم التواصل أو من البايو)، الهاتف،
الفئة، التوثيق، الأرقام، والموقع. النتائج تظهر في جدول وتُصدَّر إلى CSV أو Excel.

## 1) مفتاح الـ API
سجّل في https://hikerapi.com (أول 100 طلب مجانية) وانسخ الـ Access Key من لوحة التحكم.

## 2) التشغيل على الكمبيوتر
```
python -m pip install --upgrade streamlit starlette requests pandas openpyxl
python -m streamlit run app.py
```
لحفظ المفتاح: أنشئ `.streamlit/secrets.toml` داخل مجلد الأداة وفيه:
```
HIKERAPI_KEY = "مفتاحك"
```

## 3) (اختياري) استعمالها من الهاتف
1. ارفع `app.py` و`requirements.txt` إلى مستودع على GitHub (بدون secrets.toml).
2. من https://share.streamlit.io أنشئ تطبيقاً من المستودع (Main file: `app.py`).
3. في إعدادات التطبيق ← Secrets أضف `HIKERAPI_KEY` و`APP_PASSWORD`.
   **لا تحذف APP_PASSWORD**: بدونها أي شخص يصل للرابط يستهلك رصيدك.

## التكلفة (طلب = سعر خطتك)
| المصدر | القوائم | البروفايلات |
|---|---|---|
| Following / Followers | طلب لكل 25–100 حساب | طلب لكل حساب |
| المعلّقون | طلب لكل 15 تعليقاً | طلب لكل شخص |
| المعجبون | طلب واحد (قائمة محدودة من إنستغرام) | طلب لكل شخص |

- الحسابات الخاصة تُتخطّى دون تكلفة (الخيار مفعّل افتراضياً).
- الأداة تعرض التكلفة التقريبية قبل البدء، والفعلية بعد الانتهاء.

## مشاكل شائعة
| الرسالة | الحل |
|---|---|
| رد غير مفهوم… | غيّر «عنوان الـ API» من «إعدادات متقدمة» إلى `api.instagrapi.com` |
| الحساب خاص / تعذّر فتح الريل | القوائم والريلز متاحة للحسابات العامة فقط |
| HTTP 401 / 402 | المفتاح خاطئ أو الرصيد انتهى (الأداة تتوقف وتحفظ ما جمعته) |
| HTTP 429 كثيراً | خفّض «عدد الطلبات المتوازية» |

## تذكير
الأداة تجمع البيانات العامة فقط. عند مراسلة الناس التزم بقوانين حماية البيانات ومكافحة السبام،
وأضف دائماً طريقة لإلغاء الاشتراك.
